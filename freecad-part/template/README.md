# {{name}}

Parametric parts and assemblies, scripted in Python with FreeCAD.

| Folder | Holds |
| --- | --- |
| `design/` | one spec per part and per assembly: `<name>.spec.toml` |
| `parts/` | one module per part: `PARAMS` (every dimension, named with its unit) and `build()` |
| `assemblies/` | one module per assembly: its parts, placed by their interfaces |
| `tests/` | `test_<name>.py`: what matters about each part |
| `reference/` | STEP files of what the design must fit |
| `deliverables/` | generated by the checks: drawings, reports, bills of materials |
| `standards/` | the ruleset's library of fasteners, sizes and materials (not edited here) |

Folders appear with their first file.

## Starting a part

Every part starts from its spec: what it's for, the material and process, the envelope and
mass, its interfaces and its requirements, each with what proves it.

    codecrew scaffold part <name>    # design/<name>.spec.toml, parts/<name>.py, tests/test_<name>.py

The skeleton passes every check; fill in the spec first, then the part. Or describe the part
in a run with the ruleset's "Design a part or assembly" team, which writes the specs for
you to approve before anything is modelled.

## Commands

    codecrew check .                 # the checks the agents are held to
    python scripts/export.py         # exports/<part>.step and .stl (FreeCAD's Python)
