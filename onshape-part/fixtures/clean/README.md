# fixture-parts

Parts designed in Onshape by codecrew's Onshape designer. The design lives in Onshape; this
repository records its feature list after every run (`design/onshape/features.json`), so git
shows how the history changed, and the checks hold the design to its rules.

Set the project's Onshape document on codecrew's Projects page (the URL of the Part Studio, in
a branch made for codecrew, not your main branch).
